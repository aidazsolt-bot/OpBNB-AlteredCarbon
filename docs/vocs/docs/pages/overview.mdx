# Overview

This documentation site is part of an **independent personal experiment**:
porting and operating an opBNB archive client **on top of** a Reth version
line. It is **not** Paradigm’s Reth product, **not** an official BNB Chain
client, and **not** affiliated with either.

Binding text lives in the repository root:

- `README.md` — Project Notice
- `NOTICE-PERSONAL-USE.md` — personal / non-commercial use only

## What this tree is

- A **port** of protocol/sync work onto a chosen Reth baseline (see `plan.md`)
- Operator-oriented pages under Vocs kept only where useful for that experiment
- CI limited to this fork’s smoke + Actions scan workflows

## What this tree is not

- Not Paradigm engineering docs, contributor guides, or design history
- Not a claim on upstream Reth’s production reputation or institutional users
- Not something to open Paradigm issues/PRs against for fork-only changes

Upstream Reth (design, audits, hive, releases) remains at
[paradigmxyz/reth](https://github.com/paradigmxyz/reth). Read it there if you
need **their** material. Here we only ported onto a version of that codebase.
