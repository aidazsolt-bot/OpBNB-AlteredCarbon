# Context (why a Reth baseline?)

Upstream [paradigmxyz/reth](https://github.com/paradigmxyz/reth) is a modular Ethereum
execution client. **Their** engineering, community, and product claims are theirs.

This repository is a **port** of an opBNB archive / sync experiment **onto** a chosen
Reth version. We reuse that codebase as a baseline; we do not continue Paradigm’s
docs, support channels, or institutional narrative.

## Practical implications

- Build and run instructions here refer to **this** tree
- Design history and “we built X” essays belong upstream — removed from `docs/design`
  and `docs/crates` here
- Permitted use: personal / non-commercial — `NOTICE-PERSONAL-USE.md`
