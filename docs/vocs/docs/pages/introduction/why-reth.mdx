# Why Reth?

Upstream [paradigmxyz/reth](https://github.com/paradigmxyz/reth) is a modular Ethereum execution
client used in production by many operators. That history is why this tree still looks like Reth.

**This repository is different:** an independent personal opBNB / AlteredCarbon experiment. It is
**not** affiliated with Paradigm, Coinbase, Alchemy, Base, or BNB Chain. Do not treat marketing
claims from upstream docs as statements about this fork.

## What still applies (crate design)

- **Modularity** — components usable as libraries
- **Performance focus** — staged sync, static files, parallel work where it pays off
- **Extensibility** — SDK / ExEx patterns (see ExEx pages; treat as reference)

## What does **not** apply here

- No upstream support channel, Telegram, Homebrew tap, or public GHCR image for this fork
- No “production ready / institutional staking” claim for AlteredCarbon
- Permitted use is personal / non-commercial only — see root `README.md` and `NOTICE-PERSONAL-USE.md`
