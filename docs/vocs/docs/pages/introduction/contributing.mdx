# Contributing

This repository is an **independent personal experiment** (opBNB / AlteredCarbon), **not** the upstream
[paradigmxyz/reth](https://github.com/paradigmxyz/reth) project.

There is **no** upstream contributor program, Telegram support channel, or issue triage here.
Read the root `README.md` *Project Notice* and `NOTICE-PERSONAL-USE.md` before doing anything with
this tree.

For architecture/dev notes that still apply to the shared Reth codebase layout, see `AGENTS.md` /
`CLAUDE.md` in the repo root. Do **not** open issues or PRs against paradigmxyz/reth for changes
made only in this fork.
