# Installation

Reth runs on Linux and macOS (Windows tracked).

There are two core methods to obtain Reth in this fork:

-   [Pre-built binaries](/installation/binaries)
-   [Building from source.](/installation/source)

:::note
Docker images, Docker Compose stacks, and related CI publish jobs are **not** maintained in this
fork. Prefer native binaries (`make maxperf-op`, cargo install) and host process managers.
:::
