# Private testnets

Kurtosis / Docker-based private testnet guides from upstream Reth are **not** maintained in this
fork (Docker images and compose stacks were removed).

For experimental private networks, run native `op-reth` / `reth` binaries with your own CL and
genesis tooling, or follow upstream documentation at
[reth.rs](https://reth.rs) / [paradigmxyz/reth](https://github.com/paradigmxyz/reth).
