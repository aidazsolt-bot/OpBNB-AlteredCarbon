# Security Policy

This repository is a **personal technology/process experiment**, not a product or supported client.
See the README *Project Notice* and `NOTICE-PERSONAL-USE.md`.

## Your responsibility

**Every user is solely responsible** for assessing security, fitness for purpose, and operational risk
before building, running, or relying on this software in any way.

That includes (without limitation): review of the code and dependencies, network exposure, key and
datadir handling, consensus correctness, and any financial or operational impact of bugs or misuse.

There is **no security team**, **no vulnerability response program**, and **no warranty or liability**
from the author(s) or contributors. Use at your own risk. The software has **not** been security-audited.

If you need a supported client for production BSC/opBNB, use an official maintained client instead.

## Upstream Reth

Security issues in **unmodified upstream** [paradigmxyz/reth](https://github.com/paradigmxyz/reth)
should be reported through that project’s own security process — not via this fork.
